# Mapa de España — Estudio

Study site for a Spanish-class map quiz: the 17 comunidades autónomas plus major landmarks (mountains, rivers, seas, capes).

Modes: **Aprender** (step-by-step lessons), **Explorar**, **Localiza** (click the map), **Escribe** (spelling with accents), **Simulacro** (practice test). Progress is saved per person in the browser ("¿Quién estudia?").

Single static `index.html`, no build step. Boundary data: es-atlas (IGN); neighbors and rivers: Natural Earth.
